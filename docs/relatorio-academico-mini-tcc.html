RESUMO

O presente trabalho acadêmico documenta o planejamento, a modelagem, a implementação e a validação do SGA — Sistema de Gestão de Ambientes, uma aplicação web reativa desenvolvida para solucionar os problemas de fragmentação de informações na administração de espaços físicos em instituições de ensino. O cenário pré-existente caracterizava-se pelo uso de planilhas eletrônicas e controles manuais desarticulados, culminando em conflitos de horários em salas de aula, subutilização de laboratórios e lentidão no atendimento a chamados de manutenção predial. Para sanar tais vulnerabilidades, desenvolveu-se uma aplicação baseada na biblioteca React.js, estruturada segundo o paradigma de Single Page Application (SPA), com divisão modular de componentes, gerenciamento centralizado de estado por meio de React Hooks e consumo de API RESTful conectada ao banco de dados relacional gerenciado Supabase (PostgreSQL). A solução contempla perfis de acesso diferenciados para Coordenação, Secretaria, Docentes e Equipe de Manutenção, além de disponibilizar um canal público e responsivo para que qualquer membro da comunidade acadêmica possa comunicar falhas de infraestrutura diretamente de dispositivos móveis sem autenticação. O processo de desenvolvimento apoiou-se na metodologia ágil Kanban, no versionamento colaborativo com Git/GitHub, em práticas de engenharia de software com testes automatizados e em esteiras de integração contínua (CI/CD) no GitHub Actions, com deploy contínuo na nuvem da Vercel.


Palavras-chave: Frameworks Front-End. React.js. Single Page Application. Gestão de Ambientes. Supabase. DevOps.

1. INTRODUÇÃO

A gestão eficiente de infraestrutura física é um dos pilares para a qualidade pedagógica e a sustentabilidade operacional de instituições de ensino técnico e superior. O ambiente educacional contemporâneo abrange uma multiplicidade de espaços: salas teóricas convencionais, laboratórios especializados com equipamentos de informática e redes, auditórios para seminários e salas administrativas. A orquestração desses espaços demanda a harmonização constante entre a grade horária das turmas, a disponibilidade dos docentes e as condições operacionais dos recursos materiais instalados.

Tradicionalmente, a alocação de salas e o controle de manutenções têm sido executados de forma descentralizada e analógica, fundamentando-se em planilhas eletrônicas independentes mantidas por diferentes setores. Esse cenário engendra falhas recorrentes como sobreposição de horários, ociosidade de salas climatizadas e ausência de indicadores operacionais.

1.1. Objetivos do Trabalho

O objetivo geral deste projeto consiste em planejar, desenvolver, documentar e validar uma aplicação web reativa para a gestão integrada de ambientes institucionais. Dentre os objetivos específicos, destacam-se: implementar uma arquitetura SPA modular em React.js, estruturar a persistência relacional na nuvem Supabase, criar um canal público responsivo de manutenção e automatizar o pipeline de entrega contínua com testes e esteira de CI/CD.

2. FUNDAMENTAÇÃO TEÓRICA

Conforme destacado por Flanagan (2020), as aplicações web contemporâneas evoluíram substancialmente do paradigma estático tradicional para ecossistemas orientados a componentes e dados assíncronos. O padrão de Single Page Application (SPA) permite que a lógica de apresentação ocorra integralmente no cliente, reduzindo o tráfego de rede e garantindo transições suaves de tela sem recarregamento do navegador (BANKS; PORCELLO, 2021).

O React.js diferencia-se pela utilização do Virtual DOM e pelo algoritmo de reconciliação heurístico, o qual sincroniza no documento real exclusivamente os nós que sofreram mutação de estado. Complementarmente, Sommerville (2019) reforça que o desacoplamento entre front-end e serviços back-end mediante APIs RESTful assegura escalabilidade e facilidade de manutenção a longo prazo.

3. METODOLOGIA E DESENVOLVIMENTO

A equipe TechFlow aplicou práticas ágeis com quadro Kanban para gestão de atividades no GitHub Projects. Os requisitos foram priorizados pelo modelo MoSCoW, elegendo como MVP a autenticação por perfil, cadastros de salas/turmas, alocação com bloqueio de conflitos, canal público de sugestão e tela de triagem técnica da manutenção.

A camada visual do SGA foi dividida em componentes funcionais no diretório APP/font_end/src, consumindo serviços unificados através de api.js e folhas de estilo CSS dedicadas por contexto de negócio. A esteira de automação no GitHub Actions executa testes contínuos de integridade e garante que apenas versões aprovadas sejam disponibilizadas para os usuários finais.

4. RESULTADOS E CONSIDERAÇÕES FINAIS

A solução desenvolvida atingiu com êxito todos os critérios de qualidade funcional, arquitetural e acadêmica. A validação comprovou a impossibilidade de reservas em duplicidade, a perfeita segregação entre sugestões públicas e ordens oficiais de manutenção, bem como a precisão dos indicadores de ocupação e SLA.

Como evolução futura, planeja-se a inclusão de aplicativo móvel para leitura direta de tags patrimoniais RFID/QR Code e integração via IoT com sensores inteligentes de presença e consumo elétrico em salas de aula.
